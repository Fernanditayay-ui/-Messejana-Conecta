# 📋 Requisitos — Messejana Conecta

Este documento apresenta os requisitos funcionais e não funcionais da plataforma Messejana Conecta.

Requisitos Funcionais :
RF01 — O sistema deve permitir pesquisar estabelecimentos.

RF02 — O sistema deve permitir filtrar estabelecimentos por categoria.

RF03 — O sistema deve permitir visualizar informações de um estabelecimento.

RF04 — O sistema deve permitir visualizar eventos.

RF05 — O sistema deve permitir criar uma conta.

Requisitos não funcionais : 
RNF01 — O sistema deve possuir interface responsiva.

RNF02 — O sistema deve funcionar em navegadores modernos.

RNF03 — A interface deve ser acessível em dispositivos móveis.

RNF04 — As senhas dos usuários devem ser armazenadas de forma segura.
