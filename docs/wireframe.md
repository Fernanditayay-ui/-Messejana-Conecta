# 🎨 Wireframe — Messejana Conecta

O wireframe representa a estrutura inicial da página principal do Messejana Conecta.

A Home foi planejada para facilitar a descoberta de estabelecimentos, serviços e eventos do bairro de Messejana.

## Estrutura da Home

### 1. Header

O cabeçalho contém:

- Logo/nome do Messejana Conecta;
- Link para explorar;
- Link para eventos;
- Link para mapa;
- Botão de login.

### 2. Hero

Área principal de apresentação da plataforma.

Elementos:

- Título principal;
- Texto de apresentação;
- Barra de pesquisa;
- Elemento visual relacionado a Messejana.

### 3. Categorias

Atalhos para facilitar a descoberta de locais.

Categorias iniciais:

- Gastronomia;
- Compras;
- Serviços;
- Beleza;
- Saúde;
- Lazer.

### 4. Eventos

Seção com eventos recentes ou próximos de acontecer em Messejana.

Cada card poderá apresentar:

- Imagem;
- Nome;
- Data;
- Horário;
- Local.

### 5. Estabelecimentos

Seção destinada à descoberta de estabelecimentos locais.

Cada card poderá apresentar:

- Imagem;
- Nome;
- Categoria;
- Avaliação;
- Quantidade de avaliações;
- Endereço.

### 6. Mapa

Área destinada à visualização geográfica de estabelecimentos e eventos.

### 7. Footer

Rodapé contendo:

- Informações sobre o projeto;
- Links institucionais;
- Política de privacidade;
- Termos de uso;
- Contato;
- Redes sociais;
- Direitos autorais.

---

## Objetivo do wireframe

O wireframe tem como objetivo definir a hierarquia visual e a organização dos elementos antes da implementação da interface.

As cores, tipografia, imagens e outros elementos visuais poderão ser definidos posteriormente durante a etapa de identidade visual e desenvolvimento do frontend.
